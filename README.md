# Editor RX

Editor visual dos layouts do CISSPoder: relatórios do Gerador de Relatórios (`.REX`), etiquetas (`.EFG`/`.EFP`) e DataWindow (`.TXT`).

Precisa de chave de ativação por computador.

## Baixar

[Editor-RX.exe (versão mais nova)](https://github.com/davi-ciss/editor-rx/releases/latest/download/Editor-RX.exe)

- Abriu, instalou. Sem perguntas e sem administrador. Fica em `%LOCALAPPDATA%\Programs\Editor RX`, com atalho no Iniciar.
- Atualiza sozinho. Abrir um `Editor RX.exe` de qualquer pasta também atualiza o instalado.
- Inicia com o Windows, só no ícone da bandeja. Desliga em Ferramentas › Iniciar com o Windows.
- Desinstala em Configurações › Aplicativos › Editor RX.

Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador". Clique em "Mais informações" › "Executar assim mesmo".

## Uso com IA
O Editor RX também é o MCP do Claude Code: a IA cria, ajusta e confere relatórios pelo editor. Como configurar: [Configurar para uso com IA](Configurar%20para%20uso%20com%20IA.md).
